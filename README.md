# Nifty 500 Companies – Financial Performance Analysis

## 📊 Project Overview

This project presents an interactive Tableau dashboard for analyzing the financial performance of Nifty 500 companies. It provides insights into company profitability, revenue distribution, and sector-wise performance using data visualization techniques.

The dashboard helps users compare companies, explore sector-level trends, and understand key financial indicators.

## 🎯 Project Objectives

- Analyze the top 10 companies based on net profit.
- Compare revenue across different sectors.
- Explore the relationship between revenue and net profit.
- Understand company distribution across sectors.
- View company-level financial details through an interactive dashboard.

## 📈 Dashboard Features

### 1. Key Performance Indicators (KPIs)
- Total Net Profit
- Total Revenue
- Total Number of Companies
- Average Earnings Per Share (EPS)

### 2. Top 10 Companies by Net Profit
A bar chart comparing the top 10 companies based on net profit.

### 3. Sector-wise Revenue Analysis
A bar chart showing revenue distribution across different sectors.

### 4. Revenue vs. Net Profit
A scatter plot used to explore the relationship between company revenue and net profit.

### 5. Sector-wise Company Distribution
A treemap visualizing the distribution of companies across different sectors.

### 6. Company Financial Details
A table displaying company names, sectors, and available financial information.

### 7. Interactive Filters
- Sector
- Company Name

These filters allow users to explore specific sectors and companies.

1. Download the `.twbx` file from this repository.
2. Open Tableau Desktop or a compatible Tableau application.
3. Open the downloaded packaged workbook.
4. Explore the dashboard using the Sector and Company Name filters.
5. Analyze the financial indicators and visualizations.
